# LeaFTL in SimpleSSD

Implementation of **LeaFTL**, a learning-based Flash Translation Layer, in the **SimpleSSD** simulator. The implementation also includes modifications and improvements made as part of the project.

This work was completed as a course project for **CS531: Memory Systems and Architecture**, IIT Ropar, 2024.

### References

* **LeaFTL:** https://arxiv.org/abs/2301.00072
* **SimpleSSD:** https://github.com/SimpleSSD/SimpleSSD-Standalone

### Project Report

The project report is included in this repository and describes the implementation, modifications, experimental setup, and results.

### Note

This repository contains a course-project implementation of LeaFTL in SimpleSSD and is not the official implementation of either project.
